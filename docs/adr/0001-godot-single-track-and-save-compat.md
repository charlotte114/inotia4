# Godot 单线开发与存档兼容口径

- **2026-11-08 定：`godot/`（Godot 4.5 + C#）是唯一开发线。** 引擎侧只用 Godot，省下来的时间全部投在规则还原与内容补齐上。
- **存档承诺「本实现相邻格式可读」。** 改存档结构或校验口径就把 `SaveFormat` 加一，并在升级链里补上旧版到新版的迁移与旧档用例（见 `godot/domain/SaveGame.cs`，当前格式号 43，升级链已铺到 33）。
- **不承诺跨引擎互读，也不承诺读原版（Inotia 4 1.2.9）存档。** 读不了就走现有坏档／空槽路径，不加拒绝逻辑；原包档只作公式核验的调研材料，不进产品。

## Consequences

- 内容校验职责集中在 C# 侧：`godot/tests` 里的内容形状、跨文件引用与素材引用校验一起跑，不用再同步另一套校验脚本。
- 现阶段玩家即开发者本人：动了存档结构就得自己承担坏档风险，所以格式号加得比功能快。
- 将来若真要跨引擎互读或读原包档，需重新开规格立项，不在收尾范围内。
